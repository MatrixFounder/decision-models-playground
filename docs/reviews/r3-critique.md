### Plantings
Harness: `r3adv/plant.py` (spec `r3adv/spec.py` → `spec.json`; results `results.json`; log `plant_log.txt`). It plants one regression at a time, addresses each file by its full path under the plant copy, requires each pattern to occur exactly once, requires the sha256 to change, runs the named tests (`-x`; `tests/` means the whole suite) in their own process group with a timeout, and kills any stray `hang_app.py` or `python -m app` afterwards (none were found). It then restores the file and checks the original sha256 before the next planting.
